Ahora mismo, el repositorio tiene una carpeta para la aplicación de escritorio, para la gestión de la base de datos, a medio hacer. El contenido de la carpeta funciona con Java. Una vez descargada la carpeta RutaAviar, puede abrise en Netbeans para ejecutarse. Al ejecutar la carpeta, tratará de conectarse a una máquina virtual en el pc para acceder a su base de datos.
